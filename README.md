# LET'S TALK Web/PWA

GitHub Pages 目标地址：<https://lande2.github.io/LET-S-TALK/>

## 仓库名称说明

GitHub 仓库名不能包含空格，`LET'S TALK` 作为应用显示名称，推荐仓库名称使用 `LET-S-TALK`。

## 已实现

- 对话、旁白、图片、动画节点编辑
- 头像、图片、视频、背景音乐导入
- TXT 导入
- 论坛楼层和图片
- 手动/自动播放与打字效果
- localStorage 本地保存
- `.letstalk` 项目导入导出
- PWA 桌面安装和离线缓存

## 发布

1. 在 GitHub 新建公开仓库 `LET-S-TALK`，不要勾选自动创建 README。
2. 在仓库 Settings → Pages → Build and deployment 中选择 **GitHub Actions**。
3. 将本工程推送至 `main` 分支。
4. 等待 Actions 中 `Deploy LET'S TALK PWA to GitHub Pages` 成功。
5. 打开 <https://lande2.github.io/LET-S-TALK/>。

## 手机安装

- Android Chrome：菜单 → 安装应用/添加到主屏幕。
- iPhone Safari：分享 → 添加到主屏幕。
